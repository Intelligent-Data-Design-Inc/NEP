# V3.3.0 Sprint 1: PDB Reader Infrastructure

**Objective**: Add the legacy PDB UDF slot definitions, a `NEP_ENABLE_PDB` / `--enable-pdb` build option (default OFF), a no-op dispatch layer (`libncpdb`) that can open and close a real `.pdb` file without parsing any records, a smoke test, and a dedicated `ci-pdb.yml` CI workflow. No PDB record parsing happens in this sprint — that is Sprint 2.

---

## Background

Legacy PDB files are line-oriented fixed-column ASCII text (see the `pdb-legacy` skill at `.devin/skills/pdb-legacy/SKILL.md`). Unlike FITS, GRIB2, GeoTIFF, or DICOM, PDB requires **no external parsing library** — a custom fixed-column line reader is sufficient. This sprint nonetheless follows the same infrastructure-first pattern used for FITS (`docs/plan/v2.0.0-sprint1-fits-ci.md`, `docs/plan/v2.0.0-sprint2-fits-dispatch.md`): get the dispatch skeleton, build system wiring, and CI green before writing any real reader logic.

**Clarified decisions** (from sprint planning):
- Legacy PDB is assigned **UDF7** (mmCIF, shipping later in v3.4.0, now takes UDF8). The `pdb-legacy` and `mmcif` skill files have been updated to reflect this swap.
- `NEP_ENABLE_PDB` / `--enable-pdb` defaults to **OFF** in this sprint; flip to ON in Sprint 2 once the dispatch layer is proven, mirroring the FITS precedent exactly.
- A new dedicated `ci-pdb.yml` workflow is created, matching `ci-fits.yml`/`ci-dicom.yml` conventions, even though no extra system package is required.
- The smoke test verifies only `nc_open()`/`nc_close()` round-trip; no format-detection negative testing yet.
- `NC_PDB_initialize()` registers `nc_def_user_format()` with the literal magic string `"HEADER"`.

## Tasks

### 1. Add PDB to the UDF slot table in `include/nep.h`

```c
/** Legacy PDB format uses UDF7 slot */
#define NEP_UDF_PDB NC_UDF7

/** Legacy PDB magic: literal "HEADER" record name at the start of the file */
#define NEP_MAGIC_PDB "HEADER"

/** Legacy PDB format display name */
#define NEP_FORMAT_NAME_PDB "PDB"
```

Update the `@section udf_slots` Doxygen comment block and the `nep_udf_slots` table to list UDF7 as PDB (currently "Reserved").

### 2. Add `NEP_ENABLE_PDB` / `--enable-pdb` build options (default OFF)

**CMake (`CMakeLists.txt`)**:

```cmake
# Legacy PDB reader support (v3.3.0) - default OFF; enable with -DNEP_ENABLE_PDB=ON
option(NEP_ENABLE_PDB "Enable legacy PDB reader support" OFF)
if(NEP_ENABLE_PDB)
    set(HAVE_PDB TRUE)
endif()
```

No `find_library`/`find_path` detection is needed — there is no external dependency.

**Autotools (`configure.ac`)**:

```m4
# Legacy PDB reader support (v3.3.0) - default OFF; enable with --enable-pdb
AC_MSG_CHECKING([whether legacy PDB reader should be enabled])
AC_ARG_ENABLE([pdb],
              [AS_HELP_STRING([--enable-pdb],
                              [Enable legacy PDB reader support (default: disabled)])])
test "x$enable_pdb" = xyes || enable_pdb=no
AC_MSG_RESULT([$enable_pdb])

HAVE_PDB=no
if test "x$enable_pdb" = "xyes"; then
    HAVE_PDB=yes
    AC_DEFINE([HAVE_PDB], [1], [Define if legacy PDB reader is enabled])
fi
AM_CONDITIONAL([HAVE_PDB], [test "x$HAVE_PDB" = "xyes"])
```

Update `BUILD_NCRC` in `configure.ac` and the equivalent `.ncrc` assembly condition in `CMakeLists.txt` to include `HAVE_PDB`.

Add `#cmakedefine HAVE_PDB` to `config.h.cmake.in`.

### 3. Create dispatch and file layers

New files, following the FITS Sprint 2 no-op pattern (`src/fitsdispatch.c`, `src/fitsfile.c`):

- `include/pdbdispatch.h` — `NC_FORMATX_NC_PDB` = `NC_FORMATX_UDF7`, `NC_PDB_FILE_INFO_T` struct (placeholder: `char *path`), prototypes for `NC_PDB_open`, `NC_PDB_close`, `NC_PDB_abort`, `NC_PDB_inq_format`, `NC_PDB_inq_format_extended`, `NC_PDB_get_vara`, `NC_PDB_initialize`, `NC_PDB_finalize`.
- `src/pdbdispatch.c` — `static const NC_Dispatch PDB_dispatcher` table; `NC_PDB_initialize()` calls `nc_def_user_format(NEP_UDF_PDB, PDB_dispatch_table, NEP_MAGIC_PDB)`; `NC_PDB_finalize()` returns `NC_NOERR`.
- `src/pdbfile.c`:
  - `NC_PDB_open()`: validate mode (read-only), create a minimal `NC_FILE_INFO_T` via `nc4_file_list_add()`, set `h5->no_write = NC_TRUE`, allocate and store an empty `NC_PDB_FILE_INFO_T` with just the file path. **Does not read or parse the `.pdb` file contents.**
  - `NC_PDB_close()`: free `NC_PDB_FILE_INFO_T` and `path`.
  - `NC_PDB_abort()`: return `NC_NOERR`.
  - `NC_PDB_inq_format()` / `NC_PDB_inq_format_extended()`: return `NC_FORMATX_NC_PDB` / `NC_NOWRITE`.
  - `NC_PDB_get_vara()`: return `NC_NOERR` (no-op; no variables exist yet).

### 4. Wire the PDB library into the build systems

- `src/CMakeLists.txt`: `if(HAVE_PDB)` block building `libncpdb` from `pdbdispatch.c pdbfile.c`, linking HDF5/NetCDF-C, installing `pdbdispatch.h`.
- `src/Makefile.am`: `if HAVE_PDB` block building `libncpdb.la`.
- Add the `.ncrc` PDB fragment (`.ncrc-pdb.in`):

```ini
# Legacy PDB protein structure data (UDF slot 7)
NETCDF.UDF7.LIBRARY=@NEP_LIBDIR@/libncpdb.so
NETCDF.UDF7.INIT=NC_PDB_initialize
NETCDF.UDF7.MAGIC=HEADER
```

### 5. Ensure `test/data/PDB/*.pdb` test files are copied to the build tree

- `test/data/PDB/1J7W.pdb` and `test/data/PDB/4HHB.pdb` already exist (sourced from https://www.rcsb.org) and are exempted from the `*.pdb` gitignore rule via `!/test/data/PDB/*.pdb` in `.gitignore`.
- `test/CMakeLists.txt`: copy `test/data/PDB/` to the build tree (mirroring the `test/data/DICOM/` directory-copy pattern), gated on `HAVE_PDB`.
- `test/Makefile.am`: add both files to `EXTRA_DIST` and copy them to the build directory when `HAVE_PDB`.

### 6. Add C test `test/tst_pdb_udf.c`

- Include `pdbdispatch.h`.
- Call `NC_PDB_initialize()`.
- `nc_open("<builddir>/data/PDB/1J7W.pdb", NC_NOWRITE, &ncid)`, expect `NC_NOERR`.
- `nc_close(ncid)`.
- Print `Done.` and return 0.
- Gated on `#ifdef HAVE_PDB`.

Wire into `test/CMakeLists.txt` (`if(HAVE_PDB)` block, add test) and `test/Makefile.am` (`if HAVE_PDB` block).

### 7. Create `.github/workflows/ci-pdb.yml`

New workflow file, modeled on `ci-fits.yml`/`ci-dicom.yml` structure but simpler (no extra system library):

- **Trigger**: push and PR to `main`.
- **Matrix**: `build_system` = `cmake`, `autotools`; Fortran ON.
- **Dependencies**: standard HDF5/NetCDF-C/NetCDF-Fortran build chain, no additional `apt-get` packages for PDB itself.
- **Configure**: `-DNEP_ENABLE_PDB=ON` (CMake) / `--enable-pdb` (Autotools), other format handlers OFF.
- **Build & test**: `make -j$(nproc)` then `ctest --verbose` / `make check`.
- **Summary step**: prints build system and `HAVE_PDB` status.

Does not modify `ci.yml` — PDB stays OFF there by default (matching FITS Sprint 1 isolation).
