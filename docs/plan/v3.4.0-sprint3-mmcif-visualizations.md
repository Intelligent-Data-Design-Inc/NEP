# v3.4.0 Sprint 3: PDBx/mmCIF Visualizations

## Sprint Goal and Scope

Add visualization examples for all three existing PDBx/mmCIF test files
(`1J7W.cif`, `2W6V.cif`, `4HHB.cif`) under `examples/viz/mmCIF/`, following
the `examples/viz/PDB/` pattern established in v3.3.0. Each script opens a
test file through the NEP UDF8 mmCIF dispatch layer and produces a
publication-ready 3D scatter PNG of the atomic coordinates. This sprint is
scoped to visualization and CI wiring only; it does not change the mmCIF
dispatch layer, parser, or netCDF schema delivered in Sprint 2.

In scope:
- `examples/viz/mmCIF/_mmcif_udf.py`: a ctypes helper analogous to
  `examples/viz/PDB/_pdb_udf.py` that opens an mmCIF file with `NC_UDF8`
  (since `netCDF4.Dataset` does not expose the UDF8 mode flag) and reads
  `atom_site_Cartn_x/y/z` and `atom_site_group_PDB`.
- Three plotting scripts, one per test file: `plot_mmcif_1j7w.py`,
  `plot_mmcif_2w6v.py`, `plot_mmcif_4hhb.py`. Each produces a 3D scatter of
  `ATOM` vs `HETATM` coordinates, matching
  `examples/viz/PDB/plot_pdb_xray_structure.py`'s style (color/marker split,
  title, axis labels, `save_with_metadata()` call).
- `examples/viz/CMakeLists.txt`: register the three scripts under a new
  `if(HAVE_MMCIF)` block, copying `test/data/mmCIF/*.cif` to the build tree
  if not already copied, and appending the three artifact basenames to
  `_viz_artifacts`.
- `examples/viz/README.md`: document the new `mmCIF/` directory, scripts,
  and manual run commands.
- `docs/mmcif.md`: add a Visualization section (create the file if it does
  not already exist, following the structure of `docs/pdb.md`).
- `.github/workflows/ci-mmcif.yml`: add a Python virtual-environment setup
  step (`python3 -m venv .venv` + `pip install -r requirements.txt`) and
  pass `-DNEP_BUILD_EXAMPLES=ON -DNEP_ENABLE_VIZ_EXAMPLES=ON` in the CMake
  configure step, matching `ci-dicom.yml`.

Out of scope (deferred):
- Flipping `NEP_ENABLE_MMCIF` to default ON in `CMakeLists.txt` — reserved
  for a future "more testing" sprint, matching the roadmap's decision to
  keep this sprint scoped to visualization only.
- New mmCIF dispatch-layer features (sequence data, anisotropic
  displacement, bonds/secondary structure) — unchanged from Sprint 2's
  deferred scope.
- Fortran visualization coverage (no existing viz script uses Fortran).
- Acquiring additional mmCIF test files — this sprint visualizes the three
  files already present in `test/data/mmCIF/`.

## Plot Content

Each script:
- Opens its `.cif` file via `_mmcif_udf.py`'s `read_structure()` helper
  (mirroring `_pdb_udf.py`'s `read_structure()` signature and return shape:
  `x`/`y`/`z` as `[model][atom]` float arrays, `group` as a list of
  `"ATOM"`/`"HETATM"` strings), using the first model (`[0, :]`) since all
  three files are single-model.
- Renders a 3D scatter (`ax.scatter`) with `ATOM` rows in black `.` markers
  and `HETATM` rows in gray `^` markers, reusing
  `plot_pdb_xray_structure.py`'s exact styling (marker sizes, colors, axis
  labels in Angstroms, legend placement).
- Calls `save_with_metadata(fig, "<name>", title, caption, alt_text)` from
  `examples/viz/plot_common.py`, with `caption` under 75 words describing
  the structure and the UDF interface, matching the DICOM/PDB caption
  style.

Per-file plot names and titles:
- `1J7W.cif` -> artifact `mmcif_1j7w_structure`, e.g. title "1J7W Structure".
- `2W6V.cif` -> artifact `mmcif_2w6v_structure`, e.g. title "2W6V Structure".
- `4HHB.cif` -> artifact `mmcif_4hhb_structure`, e.g. title "4HHB Structure"
  (hemoglobin, includes `HETATM` heme groups, mirroring the PDB `4HHB.pdb`
  X-ray plot for a natural before/after comparison across formats).

Exact structure names/descriptions (residue counts, chain composition) are
confirmed by inspecting each `.cif` file's `_struct.title` /
`_entity.pdbx_description` during implementation.

## Major Tasks (Dependency Order)

1. Write `examples/viz/mmCIF/_mmcif_udf.py`: adapt `_pdb_udf.py`'s
   `read_structure()` for UDF8 (`NC_UDF8` constant, `libncmmcif.so`,
   `NC_MMCIF_initialize()`), reading `atom_site_Cartn_x/y/z` as
   `NC_DOUBLE` (per Sprint 2's schema) instead of PDB's `NC_FLOAT`, and
   `atom_site_group_PDB` as a string/char variable.
2. Write `plot_mmcif_4hhb.py` first (most direct analog to the existing
   PDB X-ray plot, easiest to validate against known-good output), then
   `plot_mmcif_1j7w.py` and `plot_mmcif_2w6v.py`.
3. Update `examples/viz/CMakeLists.txt`: add an `if(HAVE_MMCIF)` block
   that copies `mmCIF/_mmcif_udf.py` and the three plot scripts, ensures
   `test/data/mmCIF/*.cif` are present in the build tree (reusing the
   existing `test/CMakeLists.txt` copy if already done for
   `tst_mmcif_udf`), registers three `add_test()` calls with
   `FIXTURES_SETUP viz_artifacts`, and appends the three artifact
   basenames to `_viz_artifacts`.
4. Update `examples/viz/README.md`: add an `mmCIF/` bullet to the
   directory-layout list, three manual-run command examples, and extend
   the `verify_viz_artifacts.py` example invocation with the new artifact
   names.
5. Create/update `docs/mmcif.md` with a Visualization section describing
   the three plots and how to run them from an mmCIF+viz-enabled build.
6. Update `.github/workflows/ci-mmcif.yml`: add the Python venv setup step
   (`python3-venv`/`python3-pip` apt packages, `python3 -m venv .venv`,
   `pip install -r requirements.txt`), add `-DNEP_BUILD_EXAMPLES=ON` and
   `-DNEP_ENABLE_VIZ_EXAMPLES=ON` to the CMake configure invocation, and
   ensure `ctest --verbose` (already present) exercises the `viz_*` tests.
7. Local verification: configure with `-DNEP_ENABLE_MMCIF=ON
   -DNEP_BUILD_EXAMPLES=ON -DNEP_ENABLE_VIZ_EXAMPLES=ON`, run
   `ctest -R viz --output-on-failure`, inspect the three generated PNGs
   and metadata files, and re-run `tst_mmcif_udf` for regression.

  `plot_mmcif_2w6v.py`, and `plot_mmcif_4hhb.py` exist and are copied to
  the build tree by CMake.
- Configuring with `-DNEP_ENABLE_MMCIF=ON -DNEP_BUILD_EXAMPLES=ON
  -DNEP_ENABLE_VIZ_EXAMPLES=ON` succeeds.
- `ctest -R viz --output-on-failure` generates all three PNG/metadata
  pairs and `verify_viz_artifacts.py` passes.
- Each PNG is within the project's 8.0 by 6.1 inch / 150 DPI limits and has
  a valid `_metadata.txt` file (title, caption &le;75 words, alt_text).

  `NEP_ENABLE_MMCIF` both ON and OFF (default stays OFF).
