# v3.5.0 Sprint 1: Create nep_meta.h

## Sprint Goal

Add a generated build metadata header, `nep_meta.h`, that NEP and downstream projects can use to query the library version, build date, compiler, and enabled feature set at compile time.

## Scope

- Add `include/nep_meta.h.in` (the committed source template) and generate `include/nep_meta.h` at build time.
- Populate the header from CMake using `version.txt` and the existing `NEP_ENABLE_*` / `HAVE_*` build options.
- Install the generated header alongside the rest of the public API headers.
- Add a compile-only C test that exercises the generated header.
- Update relevant documentation to mention `nep_meta.h`.

## Out of Scope

- No runtime API or function for build info.
- No build-timestamp regeneration on every `make` (the build date is a configure-time value).
- No new format readers, compression features, or UDF slots.

## Major Tasks (in dependency order)

1. Inspect and mirror the netcdf-c `netcdf_meta.h` generation pattern.
   - `netcdf-c/include/netcdf_meta.h.in` is the committed template.
   - `netcdf-c/CMakeLists.txt` uses `configure_file(... @ONLY)` to produce `netcdf_meta.h` in the build tree.
   - `netcdf-c/include/CMakeLists.txt` installs the generated header from the binary directory.
   - `netcdf-c/include/.gitignore` ignores the generated `netcdf_meta.h`.

2. Create `include/nep_meta.h.in` defining at minimum:
   - `NEP_VERSION_MAJOR`, `NEP_VERSION_MINOR`, `NEP_VERSION_PATCH`, `NEP_VERSION`
   - `NEP_BUILD_DATE` (configure-time date in `YYYY-MM-DD` form)
   - `NEP_COMPILER_NAME` and `NEP_COMPILER_VERSION`
   - `NEP_HAS_<feature>` 0/1 macros for at least:
     - LZ4, BZIP2, Fortran
     - CDF, GeoTIFF, GRIB2, FITS, PDS4, DICOM, PDB, mmCIF
   - Include guards and a brief Doxygen-style header.

3. Update root `CMakeLists.txt`:
   - Parse the existing `NEP_VERSION_FROM_FILE` string into major/minor/patch components, or introduce `NEP_VERSION_MAJOR` / `NEP_VERSION_MINOR` / `NEP_VERSION_PATCH` variables.
   - Capture `CMAKE_C_COMPILER_ID` and `CMAKE_C_COMPILER_VERSION`.
   - Derive `NEP_BUILD_DATE` at configure time with `string(TIMESTAMP ...)`.
   - Emit CMake variables that match the `@...@` placeholders in `include/nep_meta.h.in` (e.g., `NEP_HAS_LZ4`, `NEP_HAS_PDB`).
   - Add `configure_file("${CMAKE_SOURCE_DIR}/include/nep_meta.h.in" "${CMAKE_BINARY_DIR}/include/nep_meta.h" @ONLY)`.

4. Add include directory handling:
   - Ensure `${CMAKE_BINARY_DIR}/include` is in the include search path so sources and tests can write `#include <nep_meta.h>`.
   - Install the generated header to `${CMAKE_INSTALL_INCLUDEDIR}`.

5. Ignore the generated `nep_meta.h` in the appropriate `.gitignore` file so it is never committed.

6. Add C compile test `test/tst_meta.c`:
   - Includes `<nep_meta.h>`.
   - Asserts that the version macros match `version.txt` (or at least are well-formed integers).
   - Checks that `NEP_HAS_LZ4` and at least one optional reader flag are defined and are either `0` or `1`.

7. Update documentation:
   - Mention `nep_meta.h` in `docs/design.md` or `docs/prd.md` build-system sections.
   - Update `README.md` if it lists installed headers.
   - Ensure `docs/Doxyfile.in` picks up `include/nep_meta.h.in` (or the generated header) so the macros are documented.

## Acceptance Criteria

- `cmake -S . -B build && cmake --build build` produces `${CMAKE_BINARY_DIR}/include/nep_meta.h`.
- `include/nep_meta.h` is not in the git index and is ignored by `.gitignore`.
- `test/tst_meta.c` compiles and passes.
- `nep_meta.h` is installed when running `cmake --install build`.

## Testing Requirements

- Run `ctest --test-dir build -R meta --output-on-failure` after a default configure and build.
- Configure with at least one optional feature enabled (e.g., `NEP_ENABLE_PDB=ON`) and verify the corresponding `NEP_HAS_PDB` macro is `1`.
- Configure with that feature disabled and verify the macro is `0`.
- Confirm the generated header is not tracked by git.

## Build System Integration

- `CMakeLists.txt`: version parsing, feature variable mapping, `configure_file` call, and (if not already covered by `src/CMakeLists.txt`) installation of the generated header.
- `test/CMakeLists.txt`: add `tst_meta.c` to the C test list.
- `.gitignore`: ignore `include/nep_meta.h`.

## Dependencies and Blockers

- None beyond the existing CMake build and `version.txt` parsing already in `CMakeLists.txt`.

## Documentation Updates

- `docs/roadmap.md` — the sprint entry already links to this plan.
- `docs/design.md` — add a short note that `nep_meta.h` exposes build-time feature flags.
- `README.md` — add `nep_meta.h` to any installed-header list.
- `docs/Doxyfile.in` — ensure `include/nep_meta.h.in` is in the Doxygen input if needed.

## Definition of Done

- `nep_meta.h.in` is committed; `nep_meta.h` is generated and ignored.
- CMake `configure_file` produces the header at configure time, with no extra build-time scripts or targets.
- A test compiles and passes in CI.
- Documentation references the header accurately.
- The sprint issue and roadmap link are updated.
