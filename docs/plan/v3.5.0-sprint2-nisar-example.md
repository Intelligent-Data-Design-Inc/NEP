# v3.5.0 Sprint 2: NISAR Example

## Sprint Goal and Scope

Add a standalone Python example under `examples/nisar/` that opens a NISAR
Level 3 Soil Moisture (SME2) product (a CF/netCDF-compliant HDF5 file) and
plots the soil moisture grid, porting the working implementation from
`/home/ed/nisar_play`. The example is documentation/demo-only: it does not
touch NEP's C library, `include/nep.h`, or the UDF dispatch framework, and
is not wired into CMake, CTest, or CI.

**In scope:**
- `examples/nisar/` Python package/scripts ported from `nisar_play`
  (`sme2.py` reader, `plots.py` plotting, `fetch.py` Earthdata bbox
  search/download, `cli.py` entry point).
- `examples/nisar/requirements.txt` for the example's Python dependencies.
- `examples/nisar/README.md` documenting setup and usage, with a committed
  example output PNG.
- Top-level `README.md` and `examples/README.md` updates pointing to the
  new example.

**Out of scope:**
- Any change to `src/`, `include/`, or NEP's UDF dispatch/format-reader
  code.
- CMake/CTest/CI integration (per roadmap: "CI does not really need to
  test this").
- Automated tests mirroring `nisar_play`'s pytest suite (manual
  command-line verification only, per clarified decisions).

## Major Tasks (dependency order)

1. Create `examples/nisar/` directory structure:
   - `examples/nisar/nisar_play/` (or flattened module) containing ported
     `sme2.py`, `plots.py`, `fetch.py`, `cli.py` from `/home/ed/nisar_play`.
   - `examples/nisar/requirements.txt` listing `xarray`, `netCDF4`,
     `matplotlib`, `cartopy`, `earthaccess`.
2. Adapt the ported CLI (`plot-sme2` equivalent, e.g.
   `python -m nisar_example` or a single `plot_nisar_sme2.py` script) so it
   runs standalone without the `nisar_play` package/build metadata
   (`pyproject.toml` entry point not required; a plain `argparse` script is
   sufficient), while preserving:
   - Required positional NISAR SME2 `.h5` path argument.
   - `--output-dir` flag (default `output/`, untracked).
   - `--show` flag for interactive display.
   - `--bbox WEST SOUTH EAST NORTH` flag that searches/downloads via
     `earthaccess`, with `~/.netrc` / `EARTHDATA_USERNAME` /
     `EARTHDATA_PASSWORD` credential resolution, matching `nisar_play`.
3. Generate the two example output PNGs (soil moisture map, footprint map)
   using the sample file at
   `/home/ed/Downloads/NISAR_L3_PR_SME2_028_005_A_020_4005_DHDH_A_20260813T125218_20260813T125253_P05023_N_F_J_001_QA_STATS.h5`
   and commit them under `examples/nisar/` (e.g. `examples/nisar/figures/`).
4. Write `examples/nisar/README.md`:
   - Explain what NISAR/SME2 is (brief, linking to `nisar-docs.asf.alaska.edu`).
   - Setup instructions (`venv`, `pip install -r requirements.txt`).
   - Usage: running against a user-supplied local file path (the large
     sample file is not committed to the repo).
   - Usage: `--bbox` fetch path and Earthdata credential setup.
   - Embed the committed PNG(s) with a caption.
5. Update `examples/README.md`'s example categories list and the top-level
   `README.md` to mention the new NISAR example and link to
   `examples/nisar/README.md`.
6. Manually verify the ported example runs end-to-end from the command
   line against the real sample file.

## Acceptance Criteria

- `examples/nisar/` exists with a working, standalone Python CLI that:
  - Opens a user-provided NISAR SME2 `.h5` file and produces a soil
    moisture PNG (and footprint PNG).
  - Supports `--output-dir` and `--show`.
  - Supports `--bbox` Earthdata search/download.
- `examples/nisar/requirements.txt` lists all needed dependencies and
  `pip install -r examples/nisar/requirements.txt` succeeds.
- `examples/nisar/README.md` documents setup/usage and embeds a committed
  example output image.
- Top-level `README.md` and `examples/README.md` reference the new example.
- No files under `src/`, `include/`, `test/`, or `.github/workflows/` are
  modified.
- Running the example against
  `/home/ed/Downloads/NISAR_L3_PR_SME2_028_005_A_020_4005_DHDH_A_20260813T125218_20260813T125253_P05023_N_F_J_001_QA_STATS.h5`
  produces a soil moisture plot without error.

## Testing Requirements

- Manual verification only (no CTest/CI integration this sprint):
  - Run `python examples/nisar/<entry_point>.py /path/to/sample.h5` and
    confirm PNG output is produced.
  - Run with `--show` to confirm interactive display works.
  - Run with `--bbox` (requires Earthdata credentials) to confirm the
    fetch path at least reaches the search/download call (can be verified
    with mocked credentials or documented as untested if no credentials
    are available in this environment).
- No new automated regression tests are added; this is an example, not a
  library feature.

## Build System Integration

None. The example is pure Python, run directly with a virtualenv; it is
intentionally **not** added to `examples/CMakeLists.txt` or any CTest
registration, matching the roadmap's note that CI does not need to test
this example.

## Dependencies and Blockers

- Requires the sample NISAR SME2 file, available locally at

  for generating the committed example PNG and manual verification.
- The `--bbox` fetch path requires a NASA Earthdata Login account for full
  end-to-end verification; this is documented as a user-provided
  credential requirement, not a blocker for merging the example.
