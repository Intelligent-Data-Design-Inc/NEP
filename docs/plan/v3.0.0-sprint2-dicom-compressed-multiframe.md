# V3.0.0 Sprint 2: Compressed Pixel Data and Multi-Frame Support

**Objective**: Extend the DICOM reader to handle encapsulated (compressed) pixel data and multi-frame images. Use the existing sample file `test/data/DICOM/0003.DCM` (JPEG Baseline Transfer Syntax) as the primary test case. Read each frame via `libdicom`, decompress the raw frame bytes, and expose the full image stack as a NetCDF variable.

---

## Background

Sprint 1 delivered a DICOM reader for native (uncompressed), single-frame images only. In practice, most clinical DICOM files use encapsulated Transfer Syntaxes such as JPEG Baseline (`1.2.840.10008.1.2.4.50`), JPEG Lossless, JPEG 2000, or RLE. Encapsulated Pixel Data uses VR `OB` with undefined length and a sequence of Items; the first Item is the Basic Offset Table, followed by one compressed fragment per frame.

`libdicom` reads encapsulated frames and returns the raw compressed bytes via `dcm_filehandle_read_frame()`. Decompression must be performed by the NEP reader using an external codec library. For JPEG Baseline, this means **libjpeg-turbo** or **libjpeg**.

Multi-frame images encode `NumberOfFrames > 1` in tag `(0028,0008)`. Each frame is read independently and stacked along a `frame` dimension.

## Tasks

### 1. Detect encapsulated Transfer Syntaxes

Read `(0002,0010)` TransferSyntaxUID from the File Meta Information. Accept the following for decompression in this sprint:

- `1.2.840.10008.1.2.4.50` JPEG Baseline (Process 1, 8-bit)

Other common UIDs may be recognized and rejected with a clear error, or supported if straightforward:

- `1.2.840.10008.1.2.4.51` JPEG Baseline (Process 2 & 4, 12-bit)
- `1.2.840.10008.1.2.4.57` JPEG Lossless, Non-Hierarchical
- `1.2.840.10008.1.2.4.70` JPEG Lossless, Non-Hierarchical, First-Order Prediction
- `1.2.840.10008.1.2.4.80` JPEG-LS Lossless
- `1.2.840.10008.1.2.4.81` JPEG-LS Near Lossless
- `1.2.840.10008.1.2.4.90` JPEG 2000 Lossless
- `1.2.840.10008.1.2.4.91` JPEG 2000
- `1.2.840.10008.1.2.5` RLE Lossless

### 2. Add JPEG decompression dependency

**CMake**: detect `libjpeg`/`libjpeg-turbo` with `find_package(JPEG)`.

```cmake
if(NEP_ENABLE_DICOM)
    find_package(JPEG REQUIRED)
    include_directories(${JPEG_INCLUDE_DIR})
    target_link_libraries(nep PRIVATE ${JPEG_LIBRARIES})
endif()
```

**Autotools**: use `AC_CHECK_LIB([jpeg], [jpeg_read_scanlines])` and `AC_CHECK_HEADERS([jpeglib.h])`.

Update `NEP_ENABLE_DICOM` so that enabling DICOM also requires JPEG for encapsulated data, or make JPEG optional and only reject encapsulated files when JPEG is missing.

### 3. Read compressed frames with libdicom

Use `dcm_filehandle_prepare_read_frame()` and `dcm_filehandle_read_frame()` to obtain a `DcmFrame *`:

```c
if (!dcm_filehandle_prepare_read_frame(&error, filehandle))
    /* handle error */;

DcmFrame *frame = dcm_filehandle_read_frame(&error, filehandle, frame_number);
if (frame == NULL)
    /* handle error */;

const void *frame_data = dcm_frame_get_data(frame);
int64_t frame_len = dcm_frame_get_size(frame);
```

The `frame_data` buffer contains the raw JPEG stream for that frame.

### 4. Decompress frames with libjpeg

For each frame:

- Initialize `struct jpeg_decompress_struct` and `jpeg_error_mgr`.
- Call `jpeg_read_header()` on the frame buffer (via a memory source manager or a temporary memory `jpeg_source_mgr`).
- Call `jpeg_start_decompress()`.
- Verify output matches the DICOM metadata: `output_width == Columns`, `output_height == Rows`, `output_components == SamplesPerPixel`.
- Read scanlines with `jpeg_read_scanlines()`.
- For `PhotometricInterpretation = "YBR_FULL_422"` or other YBR variants, convert to RGB or document that the raw YBR values are returned.
- Copy decompressed pixels into the NetCDF read buffer.

### 5. Add multi-frame dimension mapping

For images with `NumberOfFrames > 1`:

- Add a `frame` dimension of length `NumberOfFrames`.
- Variable shape becomes `[frame][row][column]` for grayscale, or `[frame][sample][row][column]` / `[frame][row][column][sample]` depending on the chosen interleaving.
- `nc_get_vara()` on the full variable reads and decompresses all requested frames.

For single-frame images, keep the shape from Sprint 1.

### 6. Update `NC_DICOM_get_vara()`

- If the requested variable is `pixel_data` and the file uses an encapsulated Transfer Syntax, decompress each requested frame on demand.
- Cache decompressed frames in memory for the duration of the `nc_get_vara()` call to avoid repeated decompression when a subset spans the same frame.
- Return `NC_EINVAL` or `NC_ENOTATT` for unsupported Transfer Syntaxes or missing decompression dependency.

### 7. Handle color photometric interpretations

For RGB images:

- SamplesPerPixel = 3.
- Expose a `sample` dimension of length 3.
- For JPEG Baseline, libjpeg usually returns interleaved RGB (`R1 G1 B1 R2 G2 B2 ...`).
- For DICOM `PlanarConfiguration = 1`, the file stores separate color planes. Map to the same interleaved NetCDF layout or document the raw layout.

For `MONOCHROME1`/`MONOCHROME2`, SamplesPerPixel = 1.

### 8. Update tests

- Modify `test/tst_dicom_udf.c` to also open `test/data/DICOM/0003.DCM` and verify:
  - Open succeeds.
  - Dimensions match Rows/Columns.
  - A small subset of `pixel_data` can be read and contains expected values (e.g., not all zeros, or compare a known pixel checksum if one can be computed offline).
- Add a multi-frame test case if a small, redistributable multi-frame DICOM sample is available.

### 9. Build system updates

- Add `JPEG_INCLUDE_DIR` / `JPEG_LIBRARIES` to the DICOM link line.
- Update `ci-dicom.yml` to install `libjpeg-turbo8-dev` or equivalent.
- Document that encapsulated DICOM support requires libjpeg.

## Implementation Details

### Frame buffer handling

`libdicom` returns the raw encapsulated fragment for each frame. The fragment is not necessarily a complete JPEG file; it is a JPEG stream suitable for `jpeg_read_header()` when read from a memory source. Implement a minimal `jpeg_source_mgr` that reads from a `const uint8_t *` buffer, or write the frame to a temporary `FILE*` and use `jpeg_stdio_src()`.

### Error handling with libjpeg

Use `jpeg_std_error()` but replace the `error_exit` callback with a longjmp-based handler that returns control to NEP and produces `NC_EIO`.

### Memory management

- Allocate one scanline buffer per frame during decompression.
- Free all libjpeg structures and frame cache in `NC_DICOM_close()`.

### Type mapping for decompressed 8-bit data

After JPEG decompression, 8-bit data is always unsigned; map to `NC_UBYTE` regardless of the original `PixelRepresentation` tag. For 12-bit JPEG, the decompressed values are still typically stored in 16-bit unsigned samples.
