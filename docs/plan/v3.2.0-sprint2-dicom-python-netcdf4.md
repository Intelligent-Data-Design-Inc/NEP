# v3.2.0 Sprint 2: Convert DICOM Visualization Scripts to Python netCDF4

## Goal

Add DICOM to the Doxygen documentation of NEP format readers. The originally planned conversion of `examples/viz/DICOM` scripts to the Python `netCDF4` library is blocked by a NetCDF-C UDF dispatch limitation and will not be implemented in this sprint.

## Original Scope and Why It Is Blocked

The sprint originally intended to replace the ctypes-based `_dicom_udf.py` helper with direct use of `netCDF4.Dataset` in the DICOM visualization scripts.

Two experiments showed this is not possible with the installed NetCDF-C / Python netCDF4 stack:

1. `netCDF4.Dataset` accepts only `mode="r"` (and other write modes); it has no API to pass the `NC_UDF6` mode flag that `nc_open()` needs to force DICOM dispatch.
2. NetCDF-C `.ncrc` UDF autoload registers a handler with a single magic string that must match the start of the file. DICOM's `DICM` magic is at byte offset 128, so `.ncrc` autoload reports `NetCDF: Unknown file format` even when the DICOM UDF library is correctly registered.

As a result, `_dicom_udf.py` and its ctypes call to `nc_open(..., NC_UDF6 | NC_NOWRITE, ...)` remain required to open DICOM files from Python.

## Revised Scope

- Add DICOM to the Doxygen main page (`docs/mainpage.md`) format readers list and installation requirements.
- Add `src/dicomdispatch.c` and `src/dicomfile.c` to the Doxygen `INPUT` list in `docs/Doxyfile.in` so the DICOM reader implementation is documented alongside the other format handlers.
- Leave `examples/viz/DICOM/*.py`, `_dicom_udf.py`, `docs/dicom.md`, and `examples/viz/README.md` unchanged.
