# V3.0.0 Sprint 1: DICOM Reader Infrastructure

**Objective**: Integrate the `libdicom` C library into NEP, add the DICOM UDF handler skeleton, and implement open/close plus metadata discovery so that a DICOM file can be recognized and its key metadata exposed through the NetCDF API. Compressed pixel data and multi-frame images are out of scope for this sprint.

---

## Background

DICOM files are medical-image SOP Instances encapsulated in the Part 10 file format: a 128-byte preamble, a `DICM` prefix, File Meta Information (Group `0x0002`, always Explicit VR Little Endian), and the Data Set encoded according to the Transfer Syntax UID in `(0002,0010)`. The existing sample file `test/data/DICOM/0003.DCM` is encoded with JPEG Baseline Transfer Syntax (`1.2.840.10008.1.2.4.50`), so its pixel data is compressed and will be addressed in Sprint 2.

This sprint uses **`libdicom`** (https://github.com/ImagingDataCommons/libdicom/) as the parsing library. It is a C library with no external dependencies, exposes `dcm_filehandle_create_from_file()`, `dcm_filehandle_get_metadata_subset()`, and frame-level read functions, and returns compressed frame data unchanged.

## Tasks

### 1. Add DICOM to the UDF slot table

Update `include/nep.h`:

```c
/** DICOM medical image format uses UDF6 slot */
#define NEP_UDF_DICOM NC_UDF6

/** DICOM magic number: "DICM" appears at byte offset 128 */
#define NEP_MAGIC_DICOM "DICM"

/** DICOM format display name */
#define NEP_FORMAT_NAME_DICOM "DICOM"
```

Update the header comments/tables in `include/nep.h` to list DICOM in UDF slot 6.

### 2. Add `NEP_ENABLE_DICOM` / `--enable-dicom` build options

**CMake (`CMakeLists.txt`)**:

```cmake
option(NEP_ENABLE_DICOM "Enable DICOM reader support via libdicom" OFF)
```

Add `libdicom` detection near the other format readers:

```cmake
if(NEP_ENABLE_DICOM)
    find_library(DICOM_LIBRARY NAMES dicom)
    find_path(DICOM_INCLUDE_DIR dicom/dicom.h)

    if(DICOM_LIBRARY AND DICOM_INCLUDE_DIR)
        message(STATUS "Found libdicom: ${DICOM_LIBRARY}")
        message(STATUS "Found libdicom headers: ${DICOM_INCLUDE_DIR}")
        include_directories(${DICOM_INCLUDE_DIR})
        set(HAVE_DICOM TRUE)
    else()
        message(FATAL_ERROR "libdicom is required for the DICOM reader. Install libdicom or use -DNEP_ENABLE_DICOM=OFF")
    endif()
endif()
```

**Autotools (`configure.ac`)**:

```m4
# DICOM reader support (v3.0.0) - default OFF; enable with --enable-dicom
AC_MSG_CHECKING([whether DICOM reader should be enabled])
AC_ARG_ENABLE([dicom],
              [AS_HELP_STRING([--enable-dicom],
                              [Enable DICOM reader support (default: disabled)])])
if test "x$enable_dicom" != xyes; then enable_dicom=no; fi
AC_MSG_RESULT([$enable_dicom])

# libdicom detection (v3.0.0)
HAVE_DICOM=no
if test "x$enable_dicom" = "xyes"; then
    AC_CHECK_HEADERS([dicom/dicom.h], [dicom_header=yes], [dicom_header=no])
    AC_CHECK_LIB([dicom], [dcm_filehandle_create_from_file],
                 [dicom_lib=yes; DICOM_LIBS="-ldicom"], [dicom_lib=no])

    if test "x$dicom_header" = "xyes" && test "x$dicom_lib" = "xyes"; then
        HAVE_DICOM=yes
        AC_DEFINE([HAVE_DICOM], [1], [Define if libdicom library is found])
        AC_MSG_NOTICE([DICOM reader enabled])
    else
        AC_MSG_ERROR([libdicom is required for the DICOM reader. Install libdicom or use --disable-dicom])
    fi
fi
AC_SUBST([DICOM_LIBS])
```

Update `config.h.cmake.in` and `config.h.in` / `nep_config.h.in` with `#cmakedefine HAVE_DICOM`.

### 3. Create dispatch and file layers

New files:

- `include/dicomdispatch.h` — public DICOM dispatch interface and `NC_DICOM_FILE_INFO_T` structure
- `src/dicomdispatch.c` — `NC_Dispatch` table and `NC_DICOM_initialize()` / `NC_DICOM_finalize()`
- `src/dicomfile.c` — `NC_DICOM_open()`, `NC_DICOM_close()`, `NC_DICOM_abort()`, format inquiry, metadata mapping

Follow the FITS pattern in `src/fitsdispatch.c` and `src/fitsfile.c`.

### 4. Implement `NC_DICOM_open()`

Using `libdicom`:

```c
DcmError *error = NULL;
DcmFilehandle *filehandle = dcm_filehandle_create_from_file(&error, path);
if (filehandle == NULL) {
    dcm_error_log(error);
    dcm_error_clear(&error);
    return NC_EINVAL;
}

const DcmDataSet *metadata = dcm_filehandle_get_metadata_subset(&error, filehandle);
if (metadata == NULL) {
    dcm_error_log(error);
    dcm_error_clear(&error);
    dcm_filehandle_destroy(filehandle);
    return NC_EINVAL;
}
```

Store `filehandle` and `metadata` in `NC_DICOM_FILE_INFO_T`. Reject compressed Transfer Syntaxes for now; allow only:

- `1.2.840.10008.1.2` Implicit VR Little Endian
- `1.2.840.10008.1.2.1` Explicit VR Little Endian
- `1.2.840.10008.1.2.2` Explicit VR Big Endian

### 5. Map DICOM metadata to NetCDF-4 model

Create dimensions and one variable for the single-frame pixel array:

- Dimensions: `row` = Rows, `column` = Columns, `sample` = SamplesPerPixel (omit if 1).
- Variable: `pixel_data` with NetCDF type derived from `BitsAllocated` and `PixelRepresentation`.
- Global attributes: PatientName, PatientID, StudyInstanceUID, SeriesInstanceUID, SOPInstanceUID, Modality, PhotometricInterpretation, TransferSyntaxUID.
- Variable attributes on `pixel_data`: BitsAllocated, BitsStored, HighBit, PixelRepresentation, SamplesPerPixel, PlanarConfiguration.

Use `dcm_dataset_get()` and `dcm_element_get_value_*()` functions from `libdicom` to read tag values.

### 6. Implement `NC_DICOM_get_vara()` for native pixel data

For uncompressed single-frame images:

- Verify the variable is `pixel_data`.
- Read the pixel data element from `libdicom`.
- For native `OW`/`OB` data, copy the requested slab into the user buffer, respecting row-major layout and optional interleaving.
- For `PlanarConfiguration = 1`, the in-file layout is planar; the reader can expose either the raw planar layout or reorder to interleaved. Document the chosen behavior.

### 7. Implement `NC_DICOM_close()` and `NC_DICOM_abort()`

Free the `libdicom` file handle and any allocated path/attribute strings.

### 8. Add a native uncompressed DICOM test file

The existing `test/data/DICOM/0003.DCM` is JPEG compressed. Add a small, freely redistributable **uncompressed** single-frame DICOM file to `test/data/DICOM/` for this sprint. Update `test/CMakeLists.txt` and `test/Makefile.am` to copy the whole `test/data/DICOM/` directory to the build tree.

## Implementation Details

### UDF registration

```c
static const NC_Dispatch DICOM_dispatcher = {
    NC_FORMATX_UDF6,
    NC_DISPATCH_VERSION,
    NC_RO_create,
    NC_DICOM_open,
    /* ... read-only dispatch stubs as in fitsdispatch.c ... */
};

NC_Dispatch *
NC_DICOM_initialize(void)
{
    DICOM_dispatch_table = &DICOM_dispatcher;
    nc_def_user_format(NEP_UDF_DICOM | NC_NETCDF4,
                       (NC_Dispatch *)DICOM_dispatch_table,
                       NEP_MAGIC_DICOM);
    return (NC_Dispatch *)&DICOM_dispatcher;
}
```

### Type mapping

| BitsAllocated | PixelRepresentation | NetCDF type |
|---------------|---------------------|-------------|
| 8 | 0 | `NC_UBYTE` |
| 8 | 1 | `NC_BYTE` |
| 16 | 0 | `NC_USHORT` |
| 16 | 1 | `NC_SHORT` |
| 32 | 0 | `NC_UINT` |
| 32 | 1 | `NC_INT` |
| 64 | 0 | `NC_UINT64` |
| 64 | 1 | `NC_INT64` |

### Error mapping

- `libdicom` returns `false` and sets `DcmError*`. Log with `dcm_error_log()` and map to `NC_EINVAL` or `NC_EIO`.
- Unsupported Transfer Syntax → `NC_ENOTATT` or `NC_EINVAL`.

## Acceptance Criteria

- `include/nep.h` defines `NEP_UDF_DICOM`, `NEP_MAGIC_DICOM`, and `NEP_FORMAT_NAME_DICOM`.
- CMake and Autotools detect `libdicom`, define `HAVE_DICOM`, and link `-ldicom`.
- `src/dicomdispatch.c` and `src/dicomfile.c` build with DICOM enabled.
- `NC_DICOM_initialize()` registers the handler in UDF6.
- `nc_open()` on an uncompressed single-frame DICOM file succeeds after `NC_DICOM_initialize()`.
- Dimensions match Rows, Columns, and SamplesPerPixel.
- Global attributes PatientName, Modality, PhotometricInterpretation, and TransferSyntaxUID are readable.
- `nc_get_vara()` reads a subset of `pixel_data` correctly.
- `test/tst_dicom_udf.c` passes under CMake and Autotools.
- `ci-dicom.yml` runs and passes for both build systems.
- Compressed Transfer Syntaxes are explicitly rejected; `test/data/DICOM/0003.DCM` is not expected to pass yet.
