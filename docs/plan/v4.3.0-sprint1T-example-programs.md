# V4.3.0 Sprint 1T: Example Programs

Source: docs/roadmap.md, "V4.3.0 - NEXTCDF4 Development / Sprint 1T".

## Goal

`examples/` contains only programs that exercise NEP features (the UDF format
readers, the moved-comparison benchmarks, and NEXTCDF-4). The generic
netCDF teaching examples — classic, netCDF-4, NcZarr, OPeNDAP, parallel
I/O, and all Fortran duplicates — are deleted because they now live in
[captainkirk99/NetCDF_Developers_Handbook](https://github.com/captainkirk99/NetCDF_Developers_Handbook)
(the mission examples already moved to
[captainkirk99/Earth_Observation_in_Practice](https://github.com/captainkirk99/Earth_Observation_in_Practice)
in v4.1.0 Sprint 3). Documentation points readers at the book
repositories instead of listing the removed programs.

## Decisions

| Topic | Decision |
|---|---|
| `examples/performance/` | **Keep in NEP** (Ed, 1c). The handbook repo's copies predate the Sprint 1C–1E `perf_disk.h` fsync/page-cache-drop timing; the NEP versions are the authoritative benchmark sources. |
| `examples/netcdf-4/chunking_performance.c` | **Move to `examples/performance/`** with its four expected CDL files. It carries Sprint 1E disk-bound timing and belongs with the kept benchmarks. The Fortran twin `f_chunking_performance.f90` is deleted with `f_netcdf-4/`. |
| `lossless.c` / `quantize.c` | **Delete** (Ed, 2a). Their LZ4/BZIP2 API moved to nep-compress in v4.2.0 and their targets/tests are already commented out — dead code. |
| `docs/ch3-fill-values.md`, `docs/background/NetCDF_Developers_Handbook_1_10.md`, `docs/background/NetCDF_Developers_Handbook_1_10_concordance.sdi` | **Delete** (Ed, 3a). Book material belonging with the handbook repo. |
| Docs pointer | **Yes** (Ed, 4a). Removed-example sections in `README.md`, `docs/examples.md`, `prd.md`, `prfaq.md`, `design.md`, `mainpage.md` are replaced by a short pointer to `captainkirk99/NetCDF_Developers_Handbook` plus an inventory of the remaining NEP/NEXTCDF-4 examples. |
| `NEP_ENABLE_OPENDAP_EXAMPLES` | Remove the CMake option, its status line, and the `NEP_HAS_OPENDAP` computation; emit `NEP_HAS_OPENDAP 0` in `nep_meta.h` so the installed macro set is unchanged. |
| `NEP_ENABLE_BENCHMARKS` | Keep — still gates `cache_tuning_validate` and the `nxt4_*_perf` tests in `examples/nextcdf4/`. |
