# v4.3.0 Sprint 1L2: Port More nc_test4 Tests

Source: docs/roadmap.md, "V4.3.0 / Sprint 1L2".

## Goal

Five of the largest upstream `nc_test4` test programs run against the
NEXTCDF-4 backend in native mode, exercising metadata definition,
attributes, dimensions, and variable storage at a scale the hand-written
`tst_nextcdf4_*` tests do not reach. Local `err_macros.h`/`nc_tests.h`
shims keep each port near-verbatim from upstream so future diffs stay
readable. Ports that expose real NEXTCDF-4 gaps are surfaced for Ed's
case-by-case call rather than silently dropped or silently fixed.

## Decisions

| Topic | Decision |
|-------|----------|
| Test set | 5 ports: `tst_camrun`, `tst_atts3`, `tst_dims`, `tst_vars`, `tst_atts1` (Ed, 1a) — the five biggest feature-compatible tests. |
| Runtime failures | Case-by-case evaluation by Ed (Ed, 2). Implementer builds and runs each port and reports each failure with the exact line and cause; interim handling is `DISABLED TRUE` + comment + status-doc entry until Ed rules (fix / file issue + disable / substitute another test). |
| Compatibility modes | Native `NC_NEXTCDF4` only (Ed, 3a). Where upstream loops over formats, the loop is kept but restricted to the netCDF-4 index, matching the `tst_rename.c` port. |
| Error macros | Shared shims `test/nextcdf4/nc_test4/err_macros.h` and `nc_tests.h` (Ed, 4a); `tst_rename.c` migrates to them. |
| Naming/registration | Upstream file and target names kept (`tst_camrun`, ...) under `test/nextcdf4/nc_test4/`; targets registered in `test/nextcdf4/CMakeLists.txt` with the existing `NCRCENV_RC`/`NETCDF_RC`/`LD_LIBRARY_PATH` environment. |
| Copyright/author | UCAR copyright header retained verbatim (ports are upstream-derived; Ed is a co-author). No NEP author block or Doxygen markup added — plain comments, per test-code convention. |

## Work items

### 1. Shared test shims in `test/nextcdf4/nc_test4/`

- `err_macros.h` — adapted verbatim from upstream
  `nc_test4/../include/err_macros.h`: drop only the `#include "config.h"`
  line. Keep `static int total_err, err`, `ERR`, `ERR_RET`, `ERR_GOTO`,
  `ERR_report`/`ERRSTAT` (mark `ERR_report` `static` if the compiler
  warns about a missing prototype), `SUMMARIZE_ERR`, `FINAL_RESULTS`,
  `FINAL_RESULTS_QUIET`. Header comment notes it is a NEP shim derived
  from upstream test infrastructure; UCAR copyright retained.
- `nc_tests.h` — NEP shim providing what the five use, as plain
  defines: `TEST_VAL_42` (42), `BAD_NAME` (`"dd//d/  "`), `MEGABYTE`,
  `HALF_MEG`, `MILLION`, `SIXTEEN_MEG`, `FOUR_MEG`, `THIRTY_TWO_MEG`,
  `SIXTY_FOUR_MEG`, `ONE_TWENTY_EIGHT_MEG`, `NC_TESTS_MAX_DIMS` (1024),
  `MAX_NUM_FORMATS` (5), `NUM_CLASSIC_TYPES` (6), `NUM_NETCDF_TYPES`
  (12), `NC_MAX_FILENAME` (4096). Includes `<netcdf.h>`, `"nep.h"`, and
  `"err_macros.h"`. Must NOT define `TEST_PNETCDF`.

### 2. Port the five tests

Copy `tst_camrun.c`, `tst_atts3.c`, `tst_dims.c`, `tst_vars.c`,
`tst_atts1.c` from `/fast/ed/netcdf-c/nc_test4/` into
`test/nextcdf4/nc_test4/` and apply, mechanically:

- Keep the UCAR copyright header.
- Drop `#include <config.h>` (`tst_camrun`, `tst_dims`). Leave the
  `nc_tests.h`/`err_macros.h` include lines untouched — they resolve to
  the local shims through the `nc_test4` include dir (work item 3).
- Add `#include "nep.h"` where absent (for `NC_NEXTCDF4`).
- `NC_NETCDF4` → `NC_NEXTCDF4` in every create mode; every
  `nc_open(path, 0 | NC_WRITE | NC_NOWRITE, ...)` gains `NC_NEXTCDF4`.
- `nc_set_default_format(fmt, NULL)` calls are removed; the
  corresponding `nc_create` gets an explicit `NC_NEXTCDF4`-based cmode.
- Upstream format loops are kept but restricted to the netCDF-4 index,
  `tst_rename` style: `/* for (format = 0; format < NUM_FORMATS; format++) */`
  followed by `for (format = 0; format < 1; format++)`.
- Sections that create netCDF-3/64BIT_OFFSET/CDF5/PnetCDF files are
  deleted outright (dead code for a NEXTCDF-4 port).
- Per-test notes: `tst_camrun` keeps `get_mem_used2` and the file-level
  `nc_set_chunk_cache`; `tst_atts3`'s parallel sections compile out via
  the missing `TEST_PNETCDF`; `tst_vars`'s `NC_STRING` `nc_inq_type`
  inquiries stay as-is (constants only).
- Build and run each port; report pass/fail to Ed per decision 2
  before registering.

### 3. Register in `test/nextcdf4/CMakeLists.txt`

- Add `${CMAKE_CURRENT_SOURCE_DIR}/nc_test4` to the ported targets'
  `target_include_directories` so `<nc_tests.h>` and `"err_macros.h"`
  resolve.
- One block per port following the existing pattern:
  `add_executable(tst_<name> nc_test4/tst_<name>.c)`, link
  `ncnextcdf4 ${NETCDF_LIBRARIES} ${NEP_HDF5_LIBRARIES}`, `add_test`,
  and the standard `ENVIRONMENT` property.
- Enabled by default; a port that fails pending Ed's decision gets
  `DISABLED TRUE` plus a comment naming the failure and its tracking
  issue/sprint — same convention as the current disabled tests.

### 4. Migrate `tst_rename.c` to the shims

Replace its inlined `ERR`/`SUMMARIZE_ERR`/`FINAL_RESULTS` block with
`#include "nc_tests.h"`; keep all other port edits and its `DISABLED`
state. Record the verified lines-167/214 in-session `nc_inq_dimid`/
`nc_inq_varid` failure (distinct from #379) in the status doc.

### 5. Status doc + failure report

- `docs/nextcdf4_status_v4_3_0.md`: update the "Full upstream `nc_test4`
  suite validation" bullet (six ports: rename + the five) and item 14 in
  "What remains before public release" (1L2 delivered five; the
  remaining suite is still unowned). Add each surfaced defect to the
