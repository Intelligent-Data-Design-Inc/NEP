# V4.3.0 Sprint 1E: Disk-Bound Timing in the Storage-Behavior Benchmarks

Source: docs/roadmap.md, "V4.3.0 / Sprint 1E".

## Goal

The remaining performance examples measure disk-bound I/O the same
way the Sprint 1C bfloat16 benchmarks do: write time ends after
`nep_perf_sync_file()`, and each read pass starts after
`nep_perf_drop_cache()`. This sprint covers the storage-behavior
programs — `cache_tuning.c`, `chunking.c`, `endianness.c`,
`fill_values.c` and `examples/netcdf-4/chunking_performance.c` — and
regenerates their committed CSVs, plot PNGs and `_metadata.txt`
captions from an optimized (`RelWithDebInfo`) build.

## Decisions

| Topic | Decision |
| --- | --- |
| Scope | `cache_tuning.c`, `chunking.c`, `endianness.c`, `fill_values.c` in `examples/performance/`, plus `examples/netcdf-4/chunking_performance.c`. The compression programs were Sprint 1D. |
| Repetitions | Keep the existing one-measurement-per-configuration structure. No `NREPS`/min-of-N. (Ed, 1D/1E split: 1a) |

| `chunking_performance.c` | Same pattern: `fsync` inside each write timer and `nep_perf_drop_cache()` before each `read_and_validate()` call. Output stays human-readable stdout; no CSV or plots. (Ed: 4a) |
| Build for reference runs | `RelWithDebInfo` (`-O2 -g -DNDEBUG`), same as Sprint 1C. Project defaults stay unchanged. |
| CI | No workflow changes. These tests run only under `NEP_ENABLE_BENCHMARKS`, which CI does not enable. |
| Spack/conda | This sprint changes nothing either recipe depends on. |

### 2. `fill_values.c` and `endianness.c`

For each program:

- Add `#include "perf_disk.h"` after the system/netcdf includes.
- **Write timer**: keep the start. Move the end to just after
  `if (nep_perf_sync_file(<file>)) { perror("nep_perf_sync_file"); return 1; }`
  placed immediately after `nc_close`. Apply to every timed file the
  program creates.
- **Read pass**: immediately before the read-timer start, call
  `if (nep_perf_drop_cache(<file>)) { perror("nep_perf_drop_cache"); return 1; }`.
  `nc_open` through `nc_close` stays the timed region.
- Update each `@file` block's timing description to "write time
  includes fsync; each read starts with the file dropped from the
  page cache" and add the `@note`: "Reference results are measured
  with `-DCMAKE_BUILD_TYPE=RelWithDebInfo` (-O2)."

### 3. `chunking.c`

- Add `#include "perf_disk.h"`.
- For each timed write (around line 234): keep `t0` where it is, and
  insert `nep_perf_sync_file` (with `perror` + `return 1` on failure)
  after the file's `nc_close`, before `elapsed` is computed.
- For each timed read pattern (around line 289): call
  `nep_perf_drop_cache` before `t0`. Where several patterns reuse one
  file, drop once per timed pass.
- Same `@file`/`@note` doc updates as item 2.
