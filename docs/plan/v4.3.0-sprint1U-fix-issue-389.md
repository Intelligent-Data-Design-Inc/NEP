# V4.3.0 Sprint 1U: Fix Issue 389 — Installed Dispatch Headers Include config.h and ncdispatch.h

Source: docs/roadmap.md, "V4.3.0 - NEXTCDF4 Development / Sprint 1U".

## Goal

Every dispatch header NEP installs is compilable by a downstream project
against `<prefix>/include` plus the netcdf-c include dir, with no
build-tree or netcdf-c-internal headers required. This applies the
`nextcdf4dispatch.h` split from #378 (Sprint 1M) to the six installed
format headers — `grib2dispatch.h`, `fitsdispatch.h`, `pds4dispatch.h`,
`dicomdispatch.h`, `pdbdispatch.h`, `mmcifdispatch.h` — and, because they
share the same defect, to the two uninstalled headers `cdfdispatch.h`
and `geotiffdispatch.h`. Backend state structs, dispatch-entry
prototypes, `*_dispatch_table` externs, `*_INIT_*` convenience macros
and third-party includes move into new per-backend internal headers in
`src/`. No installed file names change; no behavior changes.

## Decisions

| Topic | Decision |
|---|---|
| Scope | All eight headers are split: the six installed ones plus `cdfdispatch.h` and `geotiffdispatch.h` (Ed, 2026-11-23). Closes the whole defect class and prepares cdf/geotiff for future installation. |
| Internal header shape | One new `src/<fmt>internal.h` per backend (`cdfinternal.h`, `geotiffinternal.h`, `grib2internal.h`, `fitsinternal.h`, `pds4internal.h`, `dicominternal.h`, `pdbinternal.h`, `mmcifinternal.h`), each including its now-public `<fmt>dispatch.h` — mirrors `src/nextcdf4/nxt4internal.h` (Ed, 2026-11-23). |
| Public surface | Installed headers keep only `NC_FORMATX_NC_<FMT>` (with the existing `#ifdef NC_FORMATX_UDFn` / `NC_FORMATX_UDF0` fallback), `NC_<FMT>_initialize`, `NC_<FMT>_finalize`; includes limited to `<netcdf.h>`, `<netcdf_dispatch.h>`, `nep.h`. INIT macros, state structs, dispatch prototypes, `*_dispatch_table` and all third-party includes move internal (Ed, 2026-11-23). |
| Verification | Manual install probe only, as in #378: `cmake --install` to a temp prefix and compile a probe that includes each installed header. No new CTest or CI job (Ed, 2026-11-23). |

## Work items

### 1. Create the eight internal headers `src/<fmt>internal.h`

One file per backend: `cdfinternal.h`, `geotiffinternal.h`,
`grib2internal.h`, `fitsinternal.h`, `pds4internal.h`, `dicominternal.h`,
`pdbinternal.h`, `mmcifinternal.h`. Model each on
`src/nextcdf4/nxt4internal.h`:

- `/**` file block (`@file <fmt>internal.h`, `@brief` "Private state and
  shared helpers for the <FMT> UDF backend.", `@author Edward Hartnett`,
  `@date 2026-11-23`, `@copyright Intelligent Data Design, Inc. All
  rights reserved.`) and a `#ifndef <FMT>INTERNAL_H` guard.
- Includes: `"config.h"`, `"ncdispatch.h"`, `"<fmt>dispatch.h"`, plus
  whatever the backend needs — `"nep_nc4.h"` where the code uses the
  vendored netcdf-c internals, and the third-party headers the structs
  use (`<fitsio.h>` for fits, `<libxml/parser.h>`+`<libxml/tree.h>` for
  pds4, `<dicom/dicom.h>` for dicom, `<geotiff.h>`+`<geo_normalize.h>`+
  `<nc4internal.h>` for geotiff, `<grib2.h>` not needed — grib2file.c
  includes it itself).
- Move in, verbatim (names and fields unchanged): all `NC_*_INFO_T`
  structs and their supporting `#define`s, the dispatch-entry
  prototypes, `extern const NC_Dispatch *<FMT>_dispatch_table`, and the
  `<FMT>_INIT_OK`/`<FMT>_INIT_AND_ASSIGN` macros.
- `extern "C"` guards retained.

### 2. Slim the eight public headers `include/<fmt>dispatch.h`

For each of `cdfdispatch.h`, `geotiffdispatch.h`, `grib2dispatch.h`,
`fitsdispatch.h`, `pds4dispatch.h`, `dicomdispatch.h`, `pdbdispatch.h`,
`mmcifdispatch.h`:

- Replace the header with the `include/nextcdf4dispatch.h` shape:
  updated `/**` file block stating the header is installed and
  downstream-compilable (adapt the nextcdf4dispatch.h prose: "This
  header may be included by downstream projects: it depends only on
  installed netcdf-c headers and `nep.h`."), the existing include guard,
  `#include <netcdf.h>` + `<netcdf_dispatch.h>` + `"nep.h"`.
- Keep `NC_FORMATX_NC_<FMT>` exactly as today, including the
  `#ifdef NC_FORMATX_UDFn` / `#else NC_FORMATX_UDF0` fallback

  includes, state structs, supporting defines (`NC_MAX_GRIB2_MESSAGES`,
  `GRIB2_MAGIC_LEN`, `NC_GRIB2_ABBREV_LEN`, `MMCIF_*_LEN`, etc.),
  dispatch prototypes, `*_dispatch_table`, `*_INIT_*` macros.
