# NEP v3.1.0 Release Notes

## CMake-Only Build System

NEP v3.1.0 removes the Autotools build system. CMake 3.9 or newer is the sole supported build, test, installation, and documentation workflow.

Use the following commands for source builds:

```bash
cmake -S . -B build -DCMAKE_INSTALL_PREFIX=/usr/local
cmake --build build
ctest --test-dir build
cmake --install build
```

CMake options retain their existing `NEP_*` names. The removal does not change public APIs, compression filters, UDF readers, or installation layout.
