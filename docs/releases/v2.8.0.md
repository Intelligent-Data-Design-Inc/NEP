# NEP v2.8.0 - Visualization

> Add optional Python visualization examples that open NEP UDF files through `netCDF4.Dataset` and produce publication-ready grayscale PNGs with companion metadata files.

This release introduces a disabled-by-default visualization framework in `examples/viz/`. Python scripts for FITS, CDF, GeoTIFF, GRIB2, and PDS4 mission data use Matplotlib to generate book-ready figures, while CMake, Autotools, and a new `ci-viz.yml` workflow validate the build-tree `.ncrc` autoload path and output artifacts.

---

## Highlights

- **Optional Python visualization framework** (#313) — `NEP_ENABLE_VIZ_EXAMPLES` / `--enable-viz-examples`, a source-root `.venv`, and `plot_common.py` produce 150-DPI, black-and-white PNGs with `_metadata.txt` companions.
- **FITS and CDF examples** (#315, #314) — `plot_fits_image.py` and `plot_cdf_var.py` join the smoke tests; CDF UDF registration is fixed in `NC_CDF_initialize()`.
- **GeoTIFF and GRIB2 examples** (#317, #316) — `plot_geotiff_subset.py` downsamples the MODIS flood tile and `plot_grib2_grid.py` plots masked GRIB2 `WIND` cells; GeoTIFF now reports `NC_FORMAT_NETCDF4` for Python compatibility.
- **PDS4 mission examples** (#317, #318) — MESSENGER, Perseverance, MAVEN NGIMS L3, and New Horizons Alice scripts demonstrate group navigation, scaling-factor application, and 2-D spectrum plotting.
- **Publication artifact verification** (#317) — `verify_viz_artifacts.py` enforces grayscale pixels, 8 by 6.1 inch limits, metadata schema, and a 75-word caption cap.
- **Continuous integration** (#317) — `.github/workflows/ci-viz.yml` builds a source-linked `netCDF4` and runs the full visualization subset under both CMake and Autotools.

## Features

### Visualization Infrastructure (#313)

- Add `examples/viz/`, `plot_common.py`, and disabled-by-default `NEP_ENABLE_VIZ_EXAMPLES` / `--enable-viz-examples` options.
- Require a source-root `.venv` with Python 3, source-built `netCDF4`, Matplotlib, and NumPy.
- Isolate tests with build-tree `NCRCENV_RC`, `NETCDF_RC`, and `LD_LIBRARY_PATH`; `plot_common.py` writes 150-DPI grayscale PNGs no larger than 8 by 6.1 inches plus companion `_metadata.txt` files.

### FITS and CDF Examples (#315, #314)

- Add `plot_fits_image.py` (WFPC2 image) and `plot_cdf_var.py` (CDF `temperature` zVariable).
- Fix `NC_CDF_initialize()` in `src/cdfdispatch.c` to register the CDF dispatch table via `nc_def_user_format()` and tolerate `NC_EINVAL` when already registered.
- Update `.ncrc-cdf.in` and stage `test/data/tst_cdf_simple.cdf` for out-of-tree builds.

### GeoTIFF and GRIB2 Examples (#317, #316)

- Add `plot_geotiff_subset.py` for the MODIS `h00v03` flood tile with ~1,000-sample strided downsampling and `lon`/`lat` coordinate fallback.
- Add `plot_grib2_grid.py` for the GRIB2 `WIND` product with `_FillValue` masking.
- Make `NC_GEOTIFF_inq_format()` report `NC_FORMAT_NETCDF4` for Python compatibility while `NC_GEOTIFF_inq_format_extended()` still returns UDF1.

### PDS4 Mission Examples (#317, #318)

- Add `plot_pds4_messenger.py`, `plot_pds4_perseverance.py`, `plot_pds4_maven_l3.py`, and `plot_pds4_new_horizons.py` covering MESSENGER, Perseverance, MAVEN NGIMS L3, and New Horizons Alice data.
- Add `pds4_dim_list_add_unique()` in `src/pds4file.c` to avoid duplicate netCDF-4 dimension names in PDS4 file-area groups.

### Documentation, CI, and Artifact Verification (#317)

- Add `.github/workflows/ci-viz.yml`, `verify_viz_artifacts.py`, and module-level docstrings for all visualization scripts.
- Update `examples/viz/README.md`, `docs/examples.md`, `docs/design.md`, `docs/prd.md`, and `docs/prfaq.md`.

## Bug Fixes

- **CDF UDF registration** (#315) — `NC_CDF_initialize()` now registers the CDF dispatch table explicitly, matching FITS and PDS4.
- **PDS4 duplicate dimensions** (#318) — repeated axis names in the same PDS4 file-area group no longer create conflicting netCDF-4 dimensions.

---

## API Changes

- `NC_GEOTIFF_inq_format()` returns `NC_FORMAT_NETCDF4` so Python `netCDF4` accepts GeoTIFF UDF files; `NC_GEOTIFF_inq_format_extended()` still identifies UDF1 (#317).
- `NC_CDF_initialize()` now performs UDF registration via `nc_def_user_format()` (#315).

## Build System

- Add the visualization option, `examples/viz/` build rules, and `requirements.txt` for the source-root `.venv`.
- Stage scripts/input data, set the `.ncrc`/library-path/Matplotlib environment, and register conditional `viz_*` tests in CMake and Autotools.
- Update `test/CMakeLists.txt` and `test/Makefile.am` to stage the CDF test file.
- Add `.github/workflows/ci-viz.yml` for end-to-end visualization CI.

---

## Testing

- Conditional `viz_*` tests cover FITS, CDF, GeoTIFF, GRIB2, and PDS4 mission examples when the corresponding reader is enabled.
- `verify_viz_artifacts.py` validates every PNG/metadata pair for dimensions, grayscale pixels, metadata schema, and 75-word captions.
- `ci-viz.yml` exercises both CMake and Autotools with a source-built `netCDF4` and all readers enabled; disabled-by-default builds are unchanged.

NEP's example programs are companion code for *The NetCDF Developer's Handbook: The Authoritative Guide to Writing High-Performance Programs for Scientific Data Management, Second Edition* — available on [Amazon](https://www.amazon.com/dp/B0H7Q1Z75L).

## Dependencies

- Python 3 with a source-root `.venv` containing source-built `netCDF4`, Matplotlib, and NumPy.
- Existing NEP readers and external libraries (CFITSIO, NASA CDF, libgeotiff/libtiff, NCEPLIBS-g2c/Jasper, libxml2).

---

## Known Limitations

- Visualization is disabled by default and requires a configured `.venv` plus at least one UDF reader.
- The pre-existing `tst_fits_udf` HDF5-symbol link failure remains in full shared CMake FITS builds; visualization tests pass independently.
- `nc_get_vars()` and `nc_get_varm()` use default dispatch fallbacks; PDS4 grouped fields and bit fields are not yet supported.

---

## Breaking Changes

None. All visualization work is optional and disabled by default; no existing reader behavior or public API changed beyond the GeoTIFF format-inquiry compatibility correction and the CDF initialization fix.
