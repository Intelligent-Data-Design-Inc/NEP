# NEP v3.3.0 - Legacy PDB (Protein Data Bank) Reader

> Adds a read-only UDF7 handler for legacy PDB macromolecular structure files, exposing atom coordinates, per-atom identity, and unit-cell metadata through the netCDF-4 data model.

This release ships the first complete NEP reader for legacy PDB format (RCSB fixed-column text). It covers the dispatch skeleton, a fixed-column parser, multi-model coordinate support, expanded C/Fortran test coverage, and documentation/example parity with other NEP format readers.

---

## Highlights

- **Legacy PDB UDF7 handler** (#341, #344) — `NC_PDB_initialize()` registers the handler on UDF slot 7 using the `"HEADER"` magic string; `nc_open()` transparently reads `.pdb` files.
- **Fixed-column parser** (#344) — `src/pdbfile.c` parses `HEADER`, `TITLE`, `COMPND`, `SOURCE`, `CRYST1`, `MODEL`/`ENDMDL`, `ATOM`, and `HETATM` records into a netCDF-4 `model` × `atom` schema.
- **Enabled by default** (#346) — `NEP_ENABLE_PDB` now defaults to `ON` in `CMakeLists.txt`, with a dedicated `ci-pdb.yml` workflow exercising the default configuration.
- **Multi-model and missing-CRYST1 coverage** (#346) — `1GAB.pdb` (20-model NMR ensemble) and `no_cryst1.pdb` (synthetic, no `CRYST1`) extend `test/tst_pdb_udf.c` and a new `ftest/ftst_pdb_udf.F90`.
- **Documentation and visualization parity** (#347, #348) — new `docs/pdb.md`, `examples/pdb/pdb_read.c`, and two `examples/viz/PDB/` scripts.

## Features

### Legacy PDB UDF7 Reader (#341, #344)

- `include/nep.h` defines `NEP_UDF_PDB` (`NC_UDF7`), `NEP_MAGIC_PDB` (`"HEADER"`), and `NEP_FORMAT_NAME_PDB`. mmCIF is reassigned to UDF8 in preparation for v3.4.0.
- `src/pdbdispatch.c` provides the `NC_Dispatch` table and `NC_PDB_initialize()` / `NC_PDB_finalize()` registration.
- `src/pdbfile.c` reads the whole file into memory and builds a netCDF-4 dataset with:
  - Dimensions `model` (number of `MODEL`/`ENDMDL` blocks, or `1` if none) and `atom` (total `ATOM` + `HETATM` records).
  - Coordinate variables `atom_site_Cartn_x`, `atom_site_Cartn_y`, `atom_site_Cartn_z` (`NC_FLOAT`, shape `[model][atom]`).
  - Per-atom variables `atom_site_id`, `atom_site_label_atom_id`, `atom_site_label_comp_id`, `atom_site_auth_asym_id`, `atom_site_auth_seq_id`, `atom_site_occupancy`, `atom_site_B_iso_or_equiv`, `atom_site_type_symbol`, and `atom_site_group_PDB` (`"ATOM"` or `"HETATM"`).
  - Global attributes `idCode`, `classification`, `depDate`, `title`, `compnd`, `source` from `HEADER`/`TITLE`/`COMPND`/`SOURCE`, and `cell_length_a/b/c`, `cell_angle_alpha/beta/gamma`, `space_group_name_H-M`, `symmetry_Z` from `CRYST1` when present.

### Expanded PDB Test Coverage (#346)

- Adds `1GAB.pdb` (56-residue B1 domain of streptococcal protein G, 20 models, public domain) and `no_cryst1.pdb` (5-atom synthetic alanine chain, no `CRYST1` record) to `test/data/PDB/`.
- `test/tst_pdb_udf.c` verifies dimension lengths, `model` > 1 for `1GAB.pdb`, differing coordinates across models, and missing-`CRYST1` attribute behavior.
- `ftest/ftst_pdb_udf.F90` adds a Fortran open/close smoke check, using `iso_c_binding` to call `NC_PDB_initialize()` and `NF90_NOWRITE` with the `NC_UDF7` flag.
- `NEP_ENABLE_PDB` flips from `OFF` to default `ON`; `.github/workflows/ci-pdb.yml` is updated to validate the default.

### Documentation, Examples, and Visualizations (#347, #348)

- New `docs/pdb.md` format reference page documents the record-to-NetCDF mapping, enabling instructions, known limitations, and a code example.
- `docs/formats.md`, `README.md`, `docs/Doxyfile.in`, `examples/README.md`, and `examples/viz/README.md` updated for PDB.
- `examples/pdb/pdb_read.c` demonstrates `NC_PDB_initialize()`, `nc_open()`, and reading a slice of `atom_site_Cartn_*`.
- `examples/viz/PDB/_pdb_udf.py` helper plus `plot_pdb_xray_structure.py` (3D scatter of `4HHB.pdb` X-ray coordinates) and `plot_pdb_nmr_ensemble.py` (multi-model overlay of `1GAB.pdb`).

## API Changes

- New public functions `NC_PDB_initialize()` and `NC_PDB_finalize()` in `include/pdbdispatch.h`.
- Legacy PDB occupies UDF slot 7; mmCIF is reassigned to slot 8 for the upcoming v3.4.0 release.

## Build System

- `CMakeLists.txt` adds `option(NEP_ENABLE_PDB ... ON)` and `HAVE_PDB`; `config.h.cmake.in` and `.ncrc-pdb.in` updated.
- `src/CMakeLists.txt` builds `libncpdb` from `pdbdispatch.c` and `pdbfile.c` when `HAVE_PDB` is set.
- `spack/NEP/package.py` adds the `pdb` variant (default `True`) and `NEP_ENABLE_PDB` mapping, with an install check for `libncpdb.so`.
- `.github/workflows/ci-pdb.yml` runs PDB tests with `NEP_ENABLE_FORTRAN=ON` and no explicit `-DNEP_ENABLE_PDB=ON`.

---

## Testing

- `ctest --test-dir build -R pdb --output-on-failure` runs `tst_pdb_udf` and `ftst_pdb_udf`.
- `1J7W.pdb` and `4HHB.pdb` regression tests verify single-model X-ray structures (4809 and 4779 atoms, respectively).
- `1GAB.pdb` verifies 20-model NMR coordinate reads.
- `no_cryst1.pdb` verifies files without `CRYST1` open and omit unit-cell attributes.
- Full CTest suite passes with `NEP_ENABLE_PDB=ON` and `NEP_ENABLE_PDB=OFF`.

NEP's example programs are companion code for *The NetCDF Developer's Handbook: The Authoritative Guide to Writing High-Performance Programs for Scientific Data Management, Second Edition* — available on [Amazon](https://www.amazon.com/dp/B0H7Q1Z75L).

## Dependencies

- No new source dependencies for the PDB reader; it uses a custom fixed-column parser.
- `libdicom` and `libgdcm-dev` remain DICOM-only dependencies (unchanged from v3.2.0).

---

## Known Limitations

- `SEQRES`-derived sequence data is not exposed.
- Hybrid-36 encoded serial/residue numbers are not supported.
- Multi-character chain IDs are not supported.
- Legacy PDB files that do not start with a `HEADER` record are not auto-detected; call `NC_PDB_initialize()` and open with `NC_UDF7`.
